# AI 使用手册 · 把这份语料接进你的 AI 应用

本库为 AI 消费做了三种形态，按你的场景选：

| 场景 | 用哪个文件 | 怎么用 |
|---|---|---|
| 直接塞进上下文 / 系统提示词 | `data/corpus-rag.md` | 单文件约 20 万字（约 30 万+ token），可整册截取 |
| RAG 检索库 | `data/entries.jsonl` | 一条判语 = 一个 chunk，自带结构化元数据 |
| 按课程顺序处理 | `data/sections/*.json` | 每讲语义段索引，含主题与毫秒级起止 |

## 一、RAG 接入（推荐）

**切块**：不要再切。`entries.jsonl` 每行就是一个语义完整的判断，平均 78 字，
直接以行为单位建向量即可。

**元数据过滤**：`book`（六册）/`h2`（大类）/`h3`（子类）/`part`（第几讲）都是现成过滤器。
例：用户问星曜 → 先按 `book=01-stars` 过滤再向量检索；问健康 → `book=05-illness`。

```python
import json
entries = [json.loads(l) for l in open("data/entries.jsonl", encoding="utf-8")]
stars = [e for e in entries if e["book"] == "01-stars" and "破军" in e["quote"]]
```

**回放链接生成**（把出处还给用户，这是本库的灵魂）：

```python
def url(e):
    h, m, s = map(int, e["t_hms"].split(":"))
    return f"https://www.bilibili.com/video/BV1KJsLekEfA?p={e['part']}&t={h*3600+m*60+s}"
```

## 二、提示词纪律（强烈建议照抄）

把这段放进你的系统提示词：

> 引用本语料时：1）判语必须原样引用、不得改写为你自己的表述；2）每条引用后附出处
> `[第N讲 §M @时间]`；3）语料未覆盖的问题如实说「倪师课程中未见此论」，不得脑补；
> 4）涉病症内容必须提示咨询执业医师，不得给出用药剂量。

理由：这份语料的全部价值在「倪师原话+可回放出处」。AI 一旦改写转述，可信度链条就断了。

## 三、口语特性须知

- 判语是讲课口语的忠实记录（仅删赘词、补标点），不是书面语。检索 embedding 建议用支持中文口语的模型。
- 繁简：全库简体。
- `note` 字段含 `〔已按裁决改正：X→Y〕` 的，表示视频字幕原文为 X（错字），经人工裁决改正为 Y——做严格溯源比对时需知此差异，详见 `data/corrections-ledger.jsonl`。
