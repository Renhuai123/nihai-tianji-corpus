# 质量验收档案 · 这 1910 条是怎么炼出来的

体积不是数据集的说服力，可复核的质检痕迹才是。本档案公开全部质检数据。

## 一、蒸馏链（为什么 12.4 小时的课最后是 1.9 MB）

```
约 20 GB   1620×1080 视频（B 站公开，未收录）
   ↓ 裁取字幕带逐帧 OCR
约 25 万字  14 讲全量转写 · 2.1 万条带毫秒时间码的 cue（涉全文复制，永不发布）
   ↓ whisper large-v3-turbo 探针逐条交叉验证
   ↓ 语义分段 → 判语提炼（提炼比约 60%）→ 六册归类
14.9 万字  1910 条判语（本库）
```

文本每一级蒸馏掉一个数量级的载体、留下知识。《红楼梦》全本 73 万字≈2.2MB——
纯中文语料的正常密度就是如此。

## 二、双源交叉验证：逐讲一致率

## 四、人工裁决的字幕勘误（127 对，全量公开）

原字幕虽经上传者逐字校正，仍存在错别字（如「命官→命宫」「堪舆学」被 ASR 听成「看雨群」等）。
规矩：**AI 无权改字**，一切勘误由人工逐条裁决后经幂等脚本重放，全程留痕。

- 账本：`data/corrections-ledger.jsonl`（127 对，含裁决时间与上下文锚定记录）
- 重放器：`tools/apply_corrections.py`（幂等，重跑结果不变）
- 条目内痕迹：`〔已按裁决改正：X→Y〕`
