## 三、双源交叉验证：逐讲一致率

主源是视频中人工逐字校正的烧录字幕（OCR 提取）；探针是 whisper 与 FunASR 对同一音频的
两份独立转写。逐条时间轴比对，一致率 = 任一探针确证的 cue 占比（门槛 60%，脚本重算、
不采信生产方自报）：

| 学科 | 一致率区间 |
|---|---|
| 易经序卦 | 63.8% – 89.7% |
| 六十四卦 | 69.4% – 91.2%（中位 82.5%） |
| 紫微斗数 | 60.3% – 80.6% |
| 堪舆 | 74.7% – 76.9% |
| 铁板神数 | 66.2% – 75.8% |

未达标批次一律打回返工，全程有记录。典型案例：某集因 whisper 参数导致探针输出锁进
单字循环，一致率 4.7%，定位根因后重跑至 61.0%；某集因板书列混入字幕带，45.6% → 79.7%。

## 四、七道自动门禁（tools/gate_check.py）

| 门禁 | 作用 |
|---|---|
| G0 空批次防线 | 空目录不得静默通过 |
| G1 秒级时长去重 | 拦截重复视频，含 ≤2s 近似漂移报警 |
| G2 探针覆盖 ≥95% | 必须存在独立第二源 |
| G3 双源一致率 ≥60% | 脚本自算，不采信自报 |
| G4 术语白名单 + 噪声检测 | 拦截专名 ASR 崩坏与水印残片 |
| G5 出处可回溯 ≥95% | 每条出处须定位到时间重叠的源 cue 与语义段 |
| G6 无凭空新增 ≥90% | 判语文字须在其时间窗源文本中逐字命中 |

## 六、人工裁决的字幕勘误（171 对，全量公开）

原字幕虽经上传者逐字校正，仍存在错别字（如「命官→命宫」「天折→夭折」「乾力天→乾为天」）。
规矩：**AI 无权改字**，一切勘误由人工逐条裁决后经幂等脚本重放，全程留痕。

- 账本：[data/corrections-ledger.jsonl](../data/corrections-ledger.jsonl)
- 重放器：`tools/apply_corrections.py`（幂等，重跑结果不变）
- 条目内痕迹：`〔已按裁决改正：X→Y〕`
