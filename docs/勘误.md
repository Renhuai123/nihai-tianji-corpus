# 内容勘误

本库收录倪师原话，一字不改；字幕错字的人工裁决另有账本 [data/corrections-ledger.jsonl](../data/corrections-ledger.jsonl)。

本页收的是另外两类问题：

- **倪师讲解里的排盘笔误**。收录要同时满足两条：同一视频里有画面互相矛盾；按排盘规则验算可以确认。
- **与古籍明文不合的基础分类**，例如星曜的南斗、北斗归属。收录以《紫微斗数全书》原文为据，原文要写得明确。

原话照旧保留，只在条目的 `note` 字段加注：错在本句的加〔勘误：…〕，本身不错、但推论建立在错处之上的加〔注：…〕。

## 1　5上：辛丑年女命「34–43 岁十年化忌」

**命例**　辛丑年三月生，阴女，金四局；真太阳时 1961-04-19 19:48（见全盘图中宫，p09 @00:34:00）。10上又讲到同一位命主。

**倪师所讲**　文昌化忌在酉宫田宅，与太阳同宫，所以 34–43 岁整个大限化忌（[p09 §9 @00:35:43]）。10上的宫格仍把文昌化忌画在田宅（[p19 §12 @00:47:30]）。

**验算**

- **文昌应在子宫。** 19:48 是戌时。文昌按时支安，从戌宫起子时逆数，戌时生落在子宫；同一讲 00:34 的全盘图也正是画在子宫（迁移）。要落在酉宫，得是丑时生。
- **时辰本身没错。** 三月生、命宫在午，只有戌时排得出来。
- **田宅宫和大限都不化忌。** 酉宫田宅没有生年化忌；34–43 大限在丁酉宫，本身也不化忌。
- **出事的只是 1994 年。** 紫微在子宫，太阳就在酉宫。1994 甲戌年甲干太阳化忌，正落在大限宫，当年虚岁 34。所以是这一年有事，不是整整十年。倪师在同一讲 00:36:51 也说了「中间太阳星会化忌」。

**加注条目**

| 出处 | 原话（节选） | 加注 |
|---|---|---|
| [p09 §9 @00:35:43] | 文昌星啊化忌……这十年中间化忌，而刚刚好跟太阳是同宫 | 勘误 |
| [p09 §9 @00:39:14] | 她这个是田宅……化忌也在这个宫里面 | 勘误 |
| [p19 §12 @00:47:30] | 还有文昌化忌有没有在这边忌在这 | 勘误 |
| [p09 §9 @00:36:09] | 这十年中叫上不见父，下不见子，中不见夫 | 注 |

**来源**　这处错误最早由 B 站网友在《天纪·紫微斗数》视频（[BV1S7tieLE72](https://www.bilibili.com/video/BV1S7tieLE72)）评论区指出（2024-10-08）；本库依据视频画面和排盘规则复核后收录。

## 2　3上、4上：主星的南斗、北斗归属

**倪师所讲**　3上讲星曜时说「我们分南斗还有北斗」（[p05 §4 @00:26:02]），按安星的两组来讲：紫微一组（紫微、天机、太阳、武曲、天同、廉贞）称北斗星系，天府一组（天府、太阴、贪狼、巨门、天相、天梁、七杀、破军）称南斗星系。4上开头又说「都是南斗星系，七杀破军跟贪狼」（[p07 §1 @00:00:07]）。

**《全书》原文**　卷一各星问答、卷二「安身命例」都写了每颗星的归属：

| 星 | 倪师 | 《全书》 | |
|---|---|---|---|
| 紫微 | 北斗 | 中天帝座（卷二作「南北斗」） | 一致 |
| 天机 | 北斗 | 南斗第三星 | 不合 |
| 太阳 | 北斗 | 卷二作「南北斗」 | 不合 |
| 武曲 | 北斗 | 北斗第六星 | 一致 |
| 天同 | 北斗 | 南斗 | 不合 |
| 廉贞 | 北斗 | 北斗第五星 | 一致 |
| 天府 | 南斗 | 南斗主令第一星 | 一致 |
| 太阴 | 南斗 | 卷二作「南北斗」 | 不合 |
| 天梁 | 南斗 | 南斗第二星 | 一致 |
| 天相 | 南斗 | 南斗第五星 | 一致 |
| 七杀 | 南斗 | 南斗第六星 | 一致 |
| 破军 | 南斗 | 北斗第七星 | 不合 |
| 贪狼 | 南斗 | 北斗第一星（「北斗解厄之神」） | 不合 |
| 巨门 | 未明说 | 北斗第二星 | — |

14 颗主星里有 6 颗与《全书》不合。倪师是把安星的两组直接当成了北斗、南斗两系，属于成套讲错，不是一时口误。

**不受影响的说法**　倪师常说的「北斗星君」「南斗星君」「南北斗星君来会」，专指紫微、天府两颗星，和《全书》一致，这些条目不加注。

**加注条目**　本库只收录了其中两句；讲天机、太阳、太阴归属的那几句不在本库收录范围内。
