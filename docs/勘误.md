# 内容勘误

本库收录倪师原话，一字不改；字幕错字的人工裁决另有账本 [data/corrections-ledger.jsonl](../data/corrections-ledger.jsonl)。

本页收的是另一类问题：**倪师讲解里的排盘笔误**。收录要同时满足两条：

- 同一视频里有画面互相矛盾；
- 按排盘规则验算可以确认。

原话照旧保留，只在条目的 `note` 字段加注：错在本句的加〔勘误：…〕，本身不错、但推论建立在错处之上的加〔注：…〕。

## 1　5上：辛丑年女命「34–43 岁十年化忌」

**命例**　辛丑年三月生，阴女，金四局；真太阳时 1961-04-19 19:48（见全盘图中宫，p09 @00:34:00）。10上又讲到同一位命主。

**倪师所讲**　文昌化忌在酉宫田宅，与太阳同宫，所以 34–43 岁整个大限化忌（[p09 §9 @00:35:43]）。10上的宫格仍把文昌化忌画在田宅（[p19 §12 @00:47:30]）。

**验算**

- **文昌应在子宫。** 19:48 是戌时。文昌按时支安，从戌宫起子时逆数，戌时生落在子宫；同一讲 00:34 的全盘图也正是画在子宫（迁移）。要落在酉宫，得是丑时生。
- **时辰本身没错。** 三月生、命宫在午，只有戌时排得出来。
- **田宅宫和大限都不化忌。** 酉宫田宅没有生年化忌；34–43 大限在丁酉宫，本身也不化忌。
- **出事的只是 1994 年。** 紫微在子宫，太阳就在酉宫。1994 甲戌年甲干太阳化忌，正落在大限宫，当年虚岁 34。所以是这一年有事，不是整整十年。倪师在同一讲 00:36:51 也说了「中间太阳星会化忌」。
