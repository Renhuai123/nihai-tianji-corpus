# 倪海厦《天纪》结构化语料 · nihai-tianji-corpus

倪海厦先生《天纪》课程的**结构化判语语料库**：每一条都是倪师原话短引文，
带精确到秒的视频出处，按倪师自己的知识体系分册组织。

**当前覆盖：天纪 · 紫微斗数**（正片 14 讲，约 12.4 小时）——**1910 条判语**。
易经六十四卦、堪舆、铁板神数为天纪其余学科，将在后续版本加入。本仓库只收天纪，不含人纪（中医）内容。

## 为什么这份语料值得用

1. **条条可回放**：每条判语带 `[pNN §M @HH:MM:SS]` 出处，
   拼接 `https://www.bilibili.com/video/BV1KJsLekEfA?p=分P&t=秒` 即可跳到倪师亲口讲这句话的那一秒。
2. **原话不改字**：转写以视频中人工逐字校正的字幕为主源，另以 whisper 探针逐条交叉验证；
   字幕本身的错别字（如「命官→命宫」）经人工裁决改正并全部留痕（`〔已按裁决改正：…〕`）。
3. **七道质量门禁**：去重、双源交叉一致率、术语白名单、出处可回溯、无凭空新增、归类抽查等，
   全部脚本化可复现（见 `tools/`）。

## 体系结构（按倪师授课体系，非自创）

```
天纪 · 紫微斗数
├── 01 主星      十四主星与辅煞星的定性/性情/格局
├── 02 十二宫    命宫至父母宫、三方四正
├── 03 格局      吉格/凶格/结构性警示
├── 04 四化      化科/化权/化禄/化忌
├── 05 疾厄      十二地支宫配脏腑、病灾
└── 07 方法论    天纪总纲/批命顺序/学习法（07 为历史编号，无 06）
```

平行还有一条**课程轴**：14 讲 × 语义段大纲，见 `docs/课程索引.md`。
